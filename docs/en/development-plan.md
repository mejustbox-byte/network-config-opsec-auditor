# Development plan

This alpha establishes one explicit neutral JSON export, inventory checks and normalized output. Vendor configurations must be transformed externally with reviewed semantics; passing a vendor file directly is unsupported. Results can be validated, compared and rendered using the report-contract CLI.

Next milestones are an inspected vendor adapter, explicit policy provenance, rule-order modeling and isolated effective-policy comparison. Each changes the assurance scope and requires dedicated acceptance cases. Device modification, active scanning and credential handling must not appear as implicit side effects.
