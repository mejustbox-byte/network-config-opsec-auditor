# Verification procedure

Twenty-four local test methods cover the four controls, unknown evidence, IPv4/IPv6, trust unions, cross-family wildcard exclusion, TCP broad rules, invalid CIDRs/ports/flags, budgets and CLI errors/collisions. Public fixtures are synthetic and do not prove device behavior.

For a future vendor adapter, privately retain the original export, device/software version, annotation mapping and independently reviewed expected results. Test disabled, denied, unknown and overlapping cases before claiming support. Actual network probing needs a separate authorized environment and is outside this offline alpha.
