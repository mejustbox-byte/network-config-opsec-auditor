# ADR: автономный потребитель инвентаря

Приняты Python 3.12+, ipaddress, JSON, unittest и точный report-contract 0.1.0a1. CIDR-арифметика не требует сети; общая валидация сохраняет статусы и покрытие совместимыми с другими аудиторами. Bootstrap устанавливает выпущенный wheel зависимости с опубликованным SHA-256.

Сборка закрепляет setuptools 84.0.0 и wheel 0.48.0; CI использует Python 3.13 в Linux, Windows и macOS. Vendor SDK и симулятор first-match исключены до изучения и независимой проверки реальной семантики экспорта. URL-входы и динамические плагины не поддерживаются. Первичная установка требует сеть, оценка — нет.
