# Матрица проверок

| ID | Pass | Fail | Неизвестность/неприменимость |
|---|---|---|---|
| NET-001 | Источники управления внутри доверенного объединения | Источник управления вне доверенных сетей | Нет источника/аннотации; не управление — неприменимо |
| NET-002 | Нет пары /0 одного семейства со всеми портами | Пара /0 одного семейства и any ports | Нет сетей/портов или protocol unknown |
| NET-003 | Заявленный защищённый service | Заявленный незащищённый service | Неизвестный service/management; не управление — неприменимо |
| NET-004 | Значимое правило с logging true | Значимое правило с logging false | Нет significance/logging; незначимое — неприменимо |

Severity отказов: critical/high/high/medium. NET-002 применяется к tcp, udp и any и требует общего семейства адресов. Pass узкой эвристики не подтверждает достаточную сегментацию. Deny и отключённые правила неприменимы ко всем четырём проверкам; неизвестная активация/action оставляет их not_tested.

Полное покрытие определяется после объединения соседних и перекрывающихся CIDR отдельно по семействам. Две /1 сети, покрывающие весь IPv4, эквивалентны /0 для NET-002.
