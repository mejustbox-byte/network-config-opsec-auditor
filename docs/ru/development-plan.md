# План развития

Alpha устанавливает один явный нейтральный JSON-экспорт, проверки инвентаря и нормализованный выход. Vendor-конфигурация преобразуется отдельно с проверенной семантикой; прямой импорт vendor-файла не поддержан. Отчёт можно валидировать, сравнить и отображать CLI контракта.

Следующие этапы — изученный vendor-адаптер, происхождение политики, модель порядка правил и изолированное сравнение эффективной политики. Они меняют область доказательств и требуют отдельных сценариев приёмки. Изменение устройств, активные пробы и учётные данные не должны стать неявными побочными эффектами.
