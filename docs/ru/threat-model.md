# Модель угроз и ограничения

Вход может содержать неверные CIDR, ложные аннотации и приватные сетевые ID. Точные поля, строгие типы, лимиты JSON, уникальные ID, границы портов и эксклюзивный выход уменьшают обычные ошибки. Команды и сетевые endpoints не исполняются. Ошибки не повторяют источник.

Остаются ложные экспорты, перекрывающиеся правила, гонки файлов, ошибки runtime/зависимостей и ограниченный расход ресурсов. Порядок, shadowing, NAT, statefulness, зоны, маршрутизация, наследование и фактическая доступность не оцениваются. ID и scope не анонимизируются. Нет удостоверения производителя и автоматической очистки; валидность отчёта не разрешает публикацию.
