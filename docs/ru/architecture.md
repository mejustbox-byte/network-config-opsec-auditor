# Архитектура

CLI → строгий ограниченный JSON → точная модель инвентаря → CIDR и аннотации → нормализованный отчёт → эксклюзивный выход. Выпущенный opsec-report-contract 0.1.0a1 обеспечивает разбор, валидацию отчёта и семантику покрытия. Python ipaddress обрабатывает канонические сети без DNS.

Вход ограничен 8 MiB и глубиной 64. Поддержаны до 1000 правил, 128 CIDR источника/назначения на правило и 256 числовых портов. --max-rules уменьшает лимит. Каждое правило даёт NET-001–NET-004 с уникальными парами. Сырые CIDR и service не копируются, но scope/ID остаются пользовательскими идентификаторами и требуют проверки приватности.
