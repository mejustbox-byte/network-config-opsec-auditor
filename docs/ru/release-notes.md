# Alpha 0.1.0a1

Реализованы выбор neutral-json-v1, строгий ограниченный импорт, четыре проверки, IPv4/IPv6 CIDR-арифметика и выход opsec-1.0. Поставляются 24 локальных тестовых метода и двуязычные выполняемые руководства. Hosted CI и чистая установка фиксируются после выполнения.

Нет vendor-адаптера, проверки фактической доступности, симуляции порядка, сетевых проб и изменения устройств. Labels управления и значимость — заявления. Публикация PyPI не заявляется. Prerelease не даёт production-гарантий.
